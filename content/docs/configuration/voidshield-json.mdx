---
title: .voidshield.json
description: Per-repository configuration for Void Shield.
---

Add a `.voidshield.json` file to your repository root to configure Void Shield's behavior.

## ignorePaths

Glob patterns for paths to exclude from scanning.

```json title=".voidshield.json"
{
  "ignorePaths": ["tests/", "**/*.test.ts", "**/*.spec.ts"]
}
```

By default all files are scanned. Use `ignorePaths` to exclude test fixtures or generated files that may contain fake secrets.
