## GitHub Marketplace

Install Void Shield from the [GitHub Marketplace](https://github.com/marketplace).

1. Click **Install**
2. Choose which repositories to grant access to
3. Void Shield will begin scanning on the next push

## Permissions required

| Permission | Level |
|---|---|
| Checks | Read & write |
| Contents | Read |
| Metadata | Read |
| Pull requests | Read |
| Secret scanning alerts | Read |
| Security events | Read & write |
