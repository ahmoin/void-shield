Void Shield is a GitHub App that scans your codebase for security vulnerabilities on every push and pull request.

## How it works

1. Install the Void Shield GitHub App on your repository
2. Void Shield receives `push` and `pull_request` events via webhook
3. It scans changed files and posts results as GitHub Check Runs with inline annotations
4. Critical findings can block merges; informational findings appear as warnings

## What it scans

| Check | Description |
|---|---|
| `hardcoded-secret` | API keys, tokens, and passwords committed to code |
| `env-file-committed` | `.env` files accidentally committed |
| `internal-ip` | Internal IP addresses hardcoded in source |
